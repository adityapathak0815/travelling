# Aura Luxury Expeditions — Earth Odyssey

A high-performance cinematic travel navigation website featuring 1,485 frames of continuous canvas-rendered stratospheric ascents, architectural wonders, and natural sanctuaries across Earth.

---

## ✦ Key Features

- **Cinematic Canvas Engine**: 1,485 high-resolution frames synchronized smoothly with scroll inertia and dynamic frame buffering.
- **Continuous Scroll Parallax**: Simultaneous dual moving glassmorphism cards that glide along the scroll path with responsive spatial depth.
- **Editorial Typography**: Syne, Cormorant Garamond, and Space Grotesk type pairings with custom gradient fills and ambient glows.
- **Aura Mega-Menus & Search**: Interactive destination sanctuaries and curated expeditions with multi-currency conversion (USD, EUR, GBP, JPY).
- **Interactive Trip Planner & Journal**: Direct itinerary booking requests, search modal with instant tag filtering, and stratospheric dispatch notes.
- **Full Multi-Device Responsive Design**: Hand-tuned layouts and viewing corridors tailored specifically for mobile phones (iOS/Android), tablets, and widescreen laptops.

---

## 🚀 Getting Started

To run the project locally on Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

Then open your browser to `http://localhost:3000`.
